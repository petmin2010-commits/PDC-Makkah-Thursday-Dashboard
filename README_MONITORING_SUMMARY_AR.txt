PDC Monitoring Summary API
==========================
تمت إضافة مسار خفيف للمراقبة المجدولة:
GET /api/monitor/summary

هذا المسار يعيد المؤشرات التنفيذية المجمعة فقط لتقليل حجم الاستجابة وزمن الفحص.
يبقى /api/monitor/full متاحاً للتحليل الشامل عند الحاجة.
لا يغيّر هذا التحديث واجهة الداش بورد أو بيانات Google Sheet.
