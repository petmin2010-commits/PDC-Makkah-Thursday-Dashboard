واجهة مراقبة مؤشرات الأداء
============================

تمت إضافة المسار:
GET /api/monitor

يعيد مؤشرات مجمعة فقط بدون عرض صفوف أو بيانات أوامر العمل التفصيلية.

أمثلة للمؤشرات:
- إجمالي أوامر العمل
- المنجز وغير المكتمل ونسبة الإنجاز
- أوامر العمل المتأخرة ونسبة التأخير
- المشاريع والتوصيلات والعمليات
- مخالفات السلامة والتنفيذ
- المقاولون والمهندسون النشطون
- حالة المرفقات
- الطوارئ (إن كانت الورقة موجودة)
- المهام والإفادات

بعد رفع التحديث على GitHub وإتمام Render Deploy افتح:
https://YOUR-SERVICE.onrender.com/api/monitor

ملاحظة أمنية: الملف المضغوط المحدث لا يتضمن .env أو credentials.json.
Render سيستمر باستخدام Environment Variables الموجودة عليه.
للتشغيل المحلي احتفظ بملفاتك الحالية السرية داخل مجلد المشروع ولا ترفعها إلى GitHub.
