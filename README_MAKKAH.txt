PDC MAKKAH DASHBOARD - NEW PACKAGE
==================================

هذه النسخة مخصصة لمشروع PDC مكة.

الربط:
- ملف .env مضبوط على Google Sheet الخاص بمشروع مكة.
- عنوان اللوحة: PDC Makkah Master Dashboard.

تعديلات التوافق مع شيت مكة:
- أوامر العمل: 🏗️اوامر العمل
- المشاريع: ⚡المشاريع العام
- التوصيلات: 🔌التوصيلات العام
- العمليات: 🛠️العمليات بالانشاءات العام  
- الإغلاقات: 🧩الاقفالات العام
- الأصول: 🏭 الاصول
- المهام والإفادات: 📌المهام والافادات
- مخالفات التنفيذ: 🚫مخالفات التنفيذ
- مخالفات السلامة: 🚫مخالفات السلاممة
- المرفقات: حالة مرفقات المقاول
- الماليات: 💰ماليات الكهرباء

ملاحظة:
- تم إخفاء صفحة الطوارئ لأن ملف مكة الحالي لا يحتوي ورقة اشعارات الطوارئ بنفس بنية مشروع جدة.
- محاضر المخالفات غير موجودة في ملف مكة الحالي، ولذلك صفحة مخالفات التنفيذ تعمل بدونها بدل إظهار خطأ.

تشغيل محلي:
1) npm install
2) npm start
3) افتح http://localhost:3000

Render / GitHub:
- ارفع محتويات هذا المجلد كمشروع جديد.
- Build Command: npm install
- Start Command: npm start
- أضف GOOGLE_SERVICE_ACCOUNT_JSON في Environment Variables على Render إذا كنت لا ترفع credentials.json.
