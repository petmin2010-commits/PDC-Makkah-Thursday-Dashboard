PDC — Full Monitoring API

المسار الجديد:
GET /api/monitor/full

الغرض:
مراقبة شاملة لكل صفحات الداش بورد المعرفة في app-config.js دون تغيير واجهة الداش بورد.

يشمل لكل Tab:
- عدد الصفوف
- اكتمال كل حقل ونسبة الخلايا الفارغة
- عدد القيم الفريدة
- أكثر القيم تكرارًا لكل حقل
- التوزيعات المهمة: المقاول، المهندس، القسم، الحالة، التأخير، التصاريح، مراحل التنفيذ وغيرها
- إحصاءات الحقول الرقمية: المجموع، المتوسط، الحد الأدنى، الحد الأقصى
- كشف التكرارات في أرقام أوامر العمل / أرقام الإشعارات
- بصمة fingerprint لكل Snapshot لتسهيل اكتشاف أي تغيير بين الفحوصات
- قائمة بالصفحات غير المتاحة بدل تعطيل الفحص بالكامل

المسار القديم /api/monitor يبقى كما هو للتوافق.
